Conditions:-

Conditional statements are used to make decisions based on whether a condition is True or False.

if Statement
if-else statement
if-elif-else Statement
Nested if Statement
Short-Hand if
Ternary operator

if Statement:
Executes a block of code only if the condition is true.
 Syntax:
     if condition:
	   #Statement

Eg:-1
	age=20
	
	if age >= 18:
	print("Eligible to vote:")

Eg:-2
	n = int(input("Enter a number: "))

	if n % 2 == 0:
    		print("Even number")

2. if-else Statement:
Executes one block if the condition is true and another if it is false.

Syntax:-
	if(condition):
		#Statement1
	else:
		#Statement2
Eg:-1

	age = 20

	if age >= 18:
    		print("Eligible to vote")
	else:
     		print("not Eligible to vote")

Eg:-2
	
	n = int(input("Enter a number: "))

	if n % 2 == 0:
		print("Even number")
	else:
   	 	print("Odd Number")

3. if-elif-else:
It is used for to check multiple conditions.

Syntax:-
	if(condition1):
		#Statement1
	elif(condition2):
		#Statement2
	else:
		#Statement3
 
Eg1:-
	marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Fail")

Eg:-2

age = 22

if age < 13:
    print("Child")
elif age < 20:
    print("Teenager")
elif age < 60:
    print("Adult")
else:
    print("Senior Citizen")

Eg3:-

temperature = 35

if temperature >= 40:
    print("Very Hot")
elif temperature >= 30:
    print("Hot")
elif temperature >= 20:
    print("Pleasant")
else:
    print("Cold")


4. Nested if Statement:
An if statement inside another if statement.

Syntax:-
	if condition1:
   	    if condition2:
                 #Statement1

Eg1:-

age = 22
citizen = True

if age >= 18:
    if citizen:
        print("Eligible to vote")
 
    else:
        print("Not Eligible to vote")

Eg2:-

marks = 92
attendance = 85

if marks >= 90:
    if attendance >= 75:
        print("Eligible for Scholarship")
    else:
        print("Attendance is Low")
else:
    print("Not Eligible for Scholarship")

Eg3:-

balance = 10000
amount = 3000

if balance >= amount:
    if amount <= 5000:
        print("Transaction Successful")
    else:
        print("Withdrawal Limit Exceeded")
else:
    print("Insufficient Balance")
	
5. Short-Hand if:
For a single statement.

Syntax:-
	if condition: statement

Eg1:-

age = 20
if age >= 18: print("Eligible to Vote")


Eg2:-

marks = 85
if marks >= 80: print("Eligible to Scholarship")


Eg3:-

temp = 40
if temp >= 35: print("Hot")


6. Ternary operator:

Syntax:-
	value_if_true if condition else value_if_false

Eg1:-

age = 18
print("Eligible to vote") if age >= 18 else print("Not eligible to vote")

Eg2:-

marks = 70

print("Pass") if marks >= 35 else print("Fail")

Eg3:-

temp = 45

print("Hot") if marks >= 35 else print("cool")
